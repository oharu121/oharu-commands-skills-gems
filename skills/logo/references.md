# Reference study

The step that supplies constraints from outside your own defaults. Do it before
generating a single concept.

## Why it comes first

Generating cold produces variations, not alternatives. Round one of the mark
this repo now ships was twenty-four concepts that were one concept twenty-four
times: monoline geometric strokes, uniform weight, rounded caps, every single
one. Nothing about that set was wrong individually; collectively it had no range
at all, because nothing outside the model's defaults had shaped it.

Studying six real identities first changed round two completely — not because
the references were copied, but because each one contradicted an assumption that
had gone unexamined.

## 1. Pick five to eight, deliberately spread

Do not pick eight of the same kind of thing. Spread across:

- **Product/company marks** — how a mark behaves at UI scale beside a wordmark
- **Personal sites** — how identity works without a company behind it
- **Editorial/writing sites** — the register a blog or publication uses
- **At least one outside the obvious sector** — the sector's convention is what
  you are trying to see, and you cannot see it from inside

For a developer-facing site, the set that worked was Linear, Astro, Josh Comeau,
Rauno Freiberg, Anthony Fu, Maggie Appleton. Use it as a starting point, not a
list — and search for current work rather than trusting a remembered list, since
sites redesign.

## 2. Actually look at them

Screenshot each one and view the image. Do not describe a site from memory or
from its HTML; the whole point is to see what it looks like.

Capture the top of the page at a desktop width — the header is where the mark
does its work.

## 3. Tabulate contradictions, not compliments

For each reference record **what it does** and, next to it, **what you were
about to do instead**. The second column is the output that matters; a list of
things you admire changes nothing.

| Reference | What it does | What I was going to do |
| --------- | ------------ | ---------------------- |
| Linear, Astro | Solid fills, mark small and quiet | All strokes — they close up at 16px |
| Rauno, Comeau | No mark at all; type plus one committed colour | Assumed a mark was mandatory |
| Maggie Appleton | Display serif, because it is a writing site | Geometric sans, the template default |
| Anthony Fu | Personal monogram with hand character | Pure geometry cannot produce "personal" |

Four rows like that are worth more than twenty concepts.

## 4. Turn each contradiction into a territory

Every row becomes a *distinct* group in the next round — not a variation.
Territories from the table above:

- Editorial serif
- Tight grotesk with a small solid mark
- Type only, colour doing the work
- Personal monogram
- Something culturally specific to this person or project

Concepts within a territory may be variations. Concepts *across* territories
must not be. If two groups produce marks that could swap places, they were one
territory with two names.

## 5. Report it before generating

Show the table and the territory list, then generate. If the user disagrees with
a territory, that is far cheaper to fix now than after sixteen concepts exist.

## Attribution

If any of this ends up published, **link the references rather than embedding
screenshots**. They are other people's work and branding, the captures go stale
as those sites change, and the argument survives without them.
